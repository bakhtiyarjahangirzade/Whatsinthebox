Before you install.

Does it upload my files?

No. Preview rendering stays local. The update checker only requests public release metadata from GitHub.

Why might a PDF preview be blocked?

Windows can block downloaded files before invoking a preview handler. A per-file permission action is available for PDFs you trust. Password-protected and damaged files may need separate handling.

Can I remove it cleanly?

Yes. The uninstaller restores the preview registrations it replaced. Clean install, update, repair and removal passed the 1.0 verification.
